실습 진행 순서

  • 작업 지침만 바꿔 같은 쿠폰 기능을 다시 구현하게 하고, 그 효과를 비교합니다.

1낭비 확인

먼저 기본 AGENTS.md로 Codex에게 쿠폰 기능을 구현하게 합니다.
작업과 무관한 문서 본문도 입력에 포함된 상태에서, 정답 여부와 입력 token을 확인합니다.

2기법 적용

Progressive disclosure를 적용한 AGENTS.example.md로 같은 기능을 다시 구현합니다.
문서를 필요할 때 읽도록 바꿔도 정답을 유지하면서 입력 token을 줄일 수 있는지 비교합니다.

3직접 개선

이 차이를 확인한 뒤에는 강의에서 배운 기법 중 이 과제에 맞는 방법을 골라 작업 지침을 수정합니다.
수정한 지침으로 다시 실행하고, 정답을 유지하며 수정 전보다 입력 token을 더 줄였는지 확인합니다.

배운 기법으로 직접 개선

  • Progressive disclosure 적용 결과를 보고, 배운 기법 중 이 과제에 더 적용할 방법을 골라봅니다.
  • 기법별 참고 자료에서 이 실습에 적용할 힌트를 얻을 수 있습니다.
  • 선택한 기법을 작업 지침에 반영해 다시 실행하고, 수정 전 결과와 비교해 효과를 확인합니다.
기법적용 방향 예
작업별 라우팅쿠폰 작업에서 읽을 문서와 절의 범위를 조정
테스트 출력 줄이기전체 테스트 결과는 파일에 보존
요약에 남길 정보와 상세 로그를 조회할 조건을 정함
스킬로 분리쿠폰 규칙과 작업 절차 중 스킬로 분리할 내용을 정함
기본 지침과 필요할 때 조회할 내용을 구분
